# Site Personnel - Ria Insa

Un site web moderne, professionnel et minimaliste pour Mariama Diop, étudiante en ingénierie informatique.

## 🎯 Objectif

Présenter un profil sérieux, engagé et compétent, mettant en avant des projets tech, des engagements associatifs et une volonté claire de créer un impact utile dans la communauté.

## 🎨 Design & Style

- **Couleur principale** : Rose pâle (#F8C8DC)
- **Couleurs secondaires** : Blanc cassé, noir profond, gris clair
- **Style** : Minimaliste, élégant, moderne, professionnel
- **Typographie** : Poppins (titres), Inter (texte)

## 📁 Structure du Projet

```
personal-website/
├── index.html          # Page principale
├── styles.css          # Styles CSS
├── script.js           # JavaScript interactif
└── README.md           # Documentation
```

## 🧱 Sections du Site

1. **Hero Section** - Introduction avec nom, tagline et CTA
2. **À propos** - Parcours, vision et engagements
3. **Projets** - Projets tech concrets avec problème/solution/technologies/impact
4. **Ce que je construis actuellement** - Projets en cours avec barres de progression
5. **Engagement & Impact** - Clubs (ISOC, Enactus) et actions sociales
6. **Compétences** - Compétences techniques et soft skills
7. **Contact** - Email, LinkedIn et GitHub

## ⚡ Fonctionnalités

- **Design responsive** - Compatible mobile et desktop
- **Navigation fluide** - Menu hamburger pour mobile
- **Animations légères** - Hover effects, transitions, scroll reveal
- **Performances optimisées** - Chargement rapide, code optimisé
- **Accessibilité** - Structure sémantique HTML5

## 🚀 Comment lancer le site

### Option 1: Serveur local Python
```bash
python -m http.server 8000
```

### Option 2: Serveur local Node.js
```bash
npx serve .
```

### Option 3: Extension Live Server (VS Code)
1. Installer l'extension "Live Server"
2. Faire clic droit sur `index.html`
3. Sélectionner "Open with Live Server"

## 🛠 Technologies Utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Design moderne avec variables CSS

Le site est optimisé pour :
- **Desktop** (1200px+)
- **Tablette** (768px - 1199px)
- **Mobile** (< 768px)

## 🎯 Points Clés

- Positionnement professionnel mais humain
- Ambitieux mais crédible
- Simple mais impactant
- Évite la surcharge visuelle
- Pas de couleurs agressives
- Design sobre et professionnel

## 📈 Performance

- Optimisation des images
- Code CSS/JS minifié
- Lazy loading des animations
- Debounce des événements scroll

## 🔧 Personnalisation

Pour personnaliser le site :
1. Modifier les couleurs dans `:root` (styles.css)
2. Adapter le contenu dans `index.html`
3. Personnaliser les animations dans `script.js`
